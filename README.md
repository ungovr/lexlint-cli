# lexlint

A placeholder for the LexLint command line, which is not released yet.

This package does nothing but say so. `lexlint --version` prints its version, and any other
command prints a notice and exits 3, so a CI step that runs it fails rather than passing on a
lint that never happened.

See https://lexlint.io for how to run LexLint today.
